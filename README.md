Sistema de Descuentos en Python

Descripción

Mi primer proyecto de programación en Python. Es un sistema que determina si una persona puede recibir un descuento según su edad, condición de estudiante y situación de deuda.

Funcionalidades

- Solicitud de datos mediante "input()".
- Validación de respuestas.
- Identificación de descuentos para adultos mayores.
- Identificación de descuentos para estudiantes sin deuda.
- Uso de estructuras condicionales.

Conceptos de Python utilizados

- Variables.
- Tipos de datos.
- "input()" y "print()".
- "if", "elif" y "else".
- Operadores "and", "or" y "not".
- Métodos "strip()" y "capitalize()".

Requisitos

Python 3.

Cómo ejecutar

Ejecutar el archivo del proyecto en un entorno compatible con Python, como Google Colab.
